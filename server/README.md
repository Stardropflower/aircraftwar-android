# 飞机大战 · 对战服务端

网络对战（比分竞赛）的 WebSocket 服务端，Node.js + `ws` 实现，几十行核心逻辑。

## 一、启动

```bash
cd server
npm install      # 只需要装一次（会生成 node_modules）
npm start        # 启动，监听 8765 端口
```

看到这行就说明起来了：

```
飞机大战对战服务端已启动：ws://0.0.0.0:8765
```

想换端口（比如 8765 被占用）：

```bash
PORT=9000 npm start      # 改成 9000
```

> ⚠️ 注意：换了端口后，**客户端也要改成同一个端口**。客户端在「网络对战」页的
> 「服务器地址」一栏直接改即可（例如 `ws://10.0.2.2:9000`），不用重新编译。

## 二、客户端怎么连到服务端

| 运行方式 | 服务器地址填什么 | 说明 |
|---|---|---|
| Android 模拟器 | `ws://10.0.2.2:8765` | `10.0.2.2` 是模拟器访问宿主机的固定地址 |
| 真机（同一 WiFi） | `ws://192.168.x.x:8765` | 把 `192.168.x.x` 换成电脑的局域网 IP |

查电脑局域网 IP：`ipconfig` 看「IPv4 地址」。

**真机连不上时先检查：**
1. 手机和电脑是否在**同一个 WiFi / 局域网**；
2. 电脑防火墙是否放行 8765 端口（Windows 会弹窗询问，点「允许」；
   没弹就在「防火墙 → 允许应用通过」里放行 Node.js）。

## 三、协议速览

客户端 → 服务端：

```jsonc
{"type":"create", "name":"玩家A", "difficulty":"NORMAL", "target":5000}
{"type":"join",   "room":"A3F9K2", "name":"玩家B"}
{"type":"score",  "room":"A3F9K2", "score":1200, "hp":900}   // 每秒上报一次
{"type":"leave",  "room":"A3F9K2"}
{"type":"ping"}                                              // 心跳
```

服务端 → 客户端：

```jsonc
{"type":"joined", "room":"A3F9K2", "you":"A", "opponent":"玩家B", "difficulty":"NORMAL", "target":5000}
{"type":"state",  "a":{"name":"玩家A","score":1200,"hp":900},
                  "b":{"name":"玩家B","score":950,"hp":1000}}
{"type":"over",   "winner":"A", "scoreA":5000, "scoreB":4210, "reason":"达到目标分"}
{"type":"opponent_left"}
{"type":"pong"}
{"type":"error",  "message":"房间不存在"}
```

## 四、胜负判定规则（服务端权威）

1. **先到目标分者胜**：任一玩家 `score >= target`，立即判其获胜；
2. **双方阵亡比分数**：两人 `hp <= 0` 且都没到目标分时，分高者胜，同分平局；
3. **对手离开/掉线**：主动 `leave` 立即判对手胜；意外掉线给 **60 秒**重连宽限，
   超时仍判对手胜。

## 五、房间约定

- 房间码 6 位（大写字母 + 数字，**排除 O / 0 / I / 1** 这些容易看错的）；
- 断线 60 秒内用**同一个名字**重新 `join` 会自动恢复原位置并补发当前 `state`；
- 房间最长存活 30 分钟，超时自动销毁；
- 心跳：客户端每 15 秒发一次 `ping`，服务端连续 30 秒没收到任何消息判掉线。
