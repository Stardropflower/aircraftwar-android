# 使用教程

> 从"什么都没有"到"手机上能玩"，照着这份文档做就行。

---

## 〇、一分钟版本

如果你只想赶紧跑起来看看：

```powershell
# 1. 设好环境变量
$env:JAVA_HOME    = "L:\android-toolchain\android-studio\jbr"
$env:ANDROID_HOME = "L:\android-sdk"

# 2. 进项目目录（注意必须是这个 ASCII 路径）
cd L:\android-projects\AircraftWar-Android

# 3. 编译
& "L:\android-toolchain\gradle-8.11.1\bin\gradle.bat" assembleDebug --console=plain

# 4. 装到连着的手机上（手机要先开 USB 调试）
& "L:\android-sdk\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

APK 位置：`app\build\outputs\apk\debug\app-debug.apk`

## 一、你必须知道的唯一硬性约束

> ⚠️ **项目必须放在纯英文（ASCII）路径下。**
> 当前正确位置：`L:\android-projects\AircraftWar-Android`

放在中文目录（比如原来的 `雷霆战机劣质版` 文件夹）会出两种问题：

1. **编译直接报错**：`Your project path contains non-ASCII characters`
2. 即使强行绕过编译检查，**单元测试会莫名失败**（`ClassNotFoundException`，类文件明明存在）

这个坑我真踩过，实测对比过：同一套代码换到纯英文路径，测试立刻全绿。
详见 [构建环境说明](../docs/04-构建环境说明.md)。

## 三、方式一：用 Android Studio 打开（平时开发推荐）

1. 双击 `L:\android-toolchain\android-studio\bin\studio64.exe`
2. 第一次启动如果问要不要导入设置 → 选 **Do not import settings**
3. 欢迎页点 **Open**，选择 `L:\android-projects\AircraftWar-Android`
   （**选这个目录本身，不要选里面的 app 目录**）
4. 等右下角 Gradle Sync 跑完（第一次要几分钟，要联网下依赖）
5. 插上手机、开启 USB 调试后，顶部设备下拉框里会出现你的手机
6. 点绿色 ▶ 按钮 → 自动编译 + 安装 + 启动

## 四、方式二：命令行（验收现场最稳）

命令行不依赖 Android Studio 的图形界面，出问题也容易看日志。

### 1. 编译

```powershell
$env:JAVA_HOME    = "L:\android-toolchain\android-studio\jbr"
$env:ANDROID_HOME = "L:\android-sdk"
cd L:\android-projects\AircraftWar-Android

& "L:\android-toolchain\gradle-8.11.1\bin\gradle.bat" assembleDebug --console=plain
```

看到 `BUILD SUCCESSFUL` 就成了。

### 2. 跑单元测试（这个能证明核心逻辑是对的）

```powershell
& "L:\android-toolchain\gradle-8.11.1\bin\gradle.bat" testDebugUnitTest --console=plain
```

应该看到 `BUILD SUCCESSFUL`，22 个测试全过。
详细报告在 `app\build\reports\tests\testDebugUnitTest\index.html`（用浏览器打开）。

> 验收时如果老师怀疑逻辑正确性，**现场跑这个测试**比嘴上说管用得多。

### 3. 装到手机

```powershell
& "L:\android-sdk\platform-tools\adb.exe" devices
# 应该看到一行 ... device
# 如果是 unauthorized，去手机上点"允许 USB 调试"

& "L:\android-sdk\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

### 4. 启动

```powershell
& "L:\android-sdk\platform-tools\adb.exe" shell am start -n edu.hitsz.aircraftwar/.ui.MainActivity
```

### 5. 看日志（出问题的时候用）

```powershell
& "L:\android-sdk\platform-tools\adb.exe" logcat -d -s AndroidRuntime:E
```

有这条命令输出的就是崩溃信息和堆栈。

## 五、装到你的荣耀手机上（重点，国产机有几个坑）

### 步骤

1. **打开开发者选项**
   设置 → 关于手机 → 连续点「版本号」7 次 → 提示"已进入开发者模式"

2. **打开 USB 调试**
   设置 → 系统和更新 → 开发人员选项 → 打开「USB 调试」

3. **荣耀/华为机型额外要做的两件事**（很多人卡在这）
   - 关掉「**纯净模式**」：设置 → 系统和更新 → 纯净模式 → 退出
     （纯净模式只允许装应用市场来源的 App，会拦住我们的调试包）
   - 开发人员选项里如果有「**仅充电时允许调试**」之类的开关，改成允许
   - USB 连接方式选「**传输文件**」而不是「仅充电」

4. **连电脑，授权**
   插上数据线 → 手机上会弹「是否允许 USB 调试」→ 勾选「一律允许」→ 确定

5. **验证连接**

   ```powershell
   & "L:\android-sdk\platform-tools\adb.exe" devices
   ```

   要看到类似这行（后面是 `device`，不是 `unauthorized` 也不是 `offline`）：

   ```
   1a2b3c4d        device
   ```

6. **安装**

   ```powershell
   & "L:\android-sdk\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
   ```

7. 手机上找「飞机大战」图标，点开

### 如果 adb 死活连不上

退一步：直接把 APK 拷到手机上装。

1. 把 `app\build\outputs\apk\debug\app-debug.apk` 复制到手机存储
2. 手机上用文件管理器找到它，点开安装
3. 如果提示"未知来源"，允许一次即可

> 这种方式不需要 USB 调试，验收现场最不容易出岔子，**建议提前准备好**。

## 六、游戏怎么玩

### 操作

| 操作 | 效果 |
|------|------|
| **手指按住屏幕拖动** | 飞机跟着手指走（飞机会显示在手指**上方**一段距离，避免被手指挡住） |
| **松开手指** | 飞机停在原地，但**子弹会自动一直发射**（不需要点射） |
| **点右上角 ⏸ 按钮** | 暂停 / 继续 |
| **暂停状态下点画面** | 继续游戏 |
| **点右上角道具格** | 使用背包里最后捡到的道具（有道具时格子会亮起并显示「点击使用」） |

### 界面说明

```
┌──────────────────────────────────────┐
│ ┌─────────────┐  (简单)   [⏸] [ ][ ] │  ← 状态卡 / 难度 / 暂停 / 道具格
│ │ 得分    0   │                      │
│ │ 生命 ▓▓▓▓▓  │                      │
│ └─────────────┘                      │
│                                      │
│            （敌机从上面下来）           │
│                                      │
│                ↑ 你的子弹             │
│                                      │
│                 ▲ 你的飞机            │
└──────────────────────────────────────┘
```

- **左上角状态卡**：得分、生命血条（绿→黄→红）
- **顶部中间胶囊**：当前难度
- **右上角 ⏸**：暂停按钮
- **右上角两个方格**：背包，能装 2 个道具，**最右边那格高亮 = 下次使用会用这个**

### 现在的规则要点（验收时可能会被问）

| 规则 | 说明 |
|------|------|
| 撞到敌机 | **立刻死亡**（这是原版设计，不是 bug） |
| 子弹 | 自动发射，打中敌机后子弹消失（不穿透） |
| 道具 | 血包 / 火力 / 超级火力 → 进背包；炸弹 / 冰冻 → 碰到立刻生效 |
| 背包 | 容量 2，**后进先出**（最后捡到的先用） |
| 简单难度 | 没有 Boss |

> 背包里的道具**点击右上角的格子就能用**，用的是最后捡到的那个（格子上有高亮）。
> 炸弹和冰冻是碰到就立刻生效，不进背包。

## 七、用模拟器跑（不方便连手机时）

模拟器已经装好了，名字叫 `aw35`。

```powershell
$env:ANDROID_HOME = "L:\android-sdk"

# 启动（-no-window 表示不弹窗口，只在后台跑；想看到画面就去掉这个参数）
& "L:\android-sdk\emulator\emulator.exe" -avd aw35 -no-snapshot -gpu swiftshader_indirect

# 等它启动完（约 40 秒），然后照常 adb 安装
& "L:\android-sdk\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

**截图**（调试时很有用）：

```powershell
# 注意：必须用 cmd 重定向，PowerShell 的 > 会破坏 PNG 二进制
cmd /c "L:\android-sdk\platform-tools\adb.exe exec-out screencap -p > shot.png"
```

## 八、常见问题

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| `Your project path contains non-ASCII characters` | 项目放在中文路径 | 移到 `L:\android-projects\` 这类纯英文路径 |
| 单测 `ClassNotFoundException`，但 class 文件在 | 同上，路径含中文 | 同上 |
| `Missing dependency: lib\gson...` | 这个报错是 Windows 版的，安卓项目不会出现 | —— |
| 编译时下载依赖很慢/失败 | 网络问题（要连 google() 仓库） | 挂代理，或重试；依赖下过一次就有缓存 |
| `adb devices` 显示 `unauthorized` | 手机上没点允许 | 重新插拔，手机上点「一律允许」 |
| `adb devices` 列表是空的 | USB 调试没开 / 数据线只能充电 | 换线、换 USB 口、重开 USB 调试 |
| 荣耀手机装不上，提示"应用来源未知" | 纯净模式 | 设置里退出纯净模式 |
| 安装时报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 手机上已有签名不同的旧版本 | 先 `adb uninstall edu.hitsz.aircraftwar` 再装 |
| 游戏黑屏但没崩 | 资源没打进去 / 加载失败 | 看 `adb logcat` 里 `资源加载失败` 字样 |
| 飞机位置偏移、被手指挡住 | 这是刻意的（飞机在手指上方 70 像素） | 正常，不用改 |

## 九、验收现场的建议

1. **提前装好**：别现场编译，网络和路径都可能出意外。提前 `adb install` 好，现场直接打开。
2. **准备两条路**：USB 调试 + APK 文件拷贝，一条不通走另一条。
3. **准备跑测试**：老师要是质疑逻辑，现场 `testDebugUnitTest` 跑一遍。
4. **打开 Android Studio 提前索引完**：现场打开代码别等索引转圈。
5. **手机电量**：演示到一半没电就尴尬了。
