## 验收时的演示顺序（照着点就行）

1. 打开 App → 看到菜单（三个难度按钮）
2. 点「简单 EASY」→ 进入游戏
3. 手指按住屏幕拖动 → 飞机跟着手指走（注意飞机在手指上方一点，不会被挡住）
4. 松开手指 → 飞机会停在原地，但**子弹一直在自动发射**
5. 让飞机撞一架敌机 → 画面变暗，弹出「游戏结束，本局得分 XX」
6. 点「返回」→ 回到菜单
7. 再进一次，点右上角的 ⏸ 按钮 → 出现「已暂停 / 点击继续」
8. 点一下画面 → 继续游戏
9. 回到菜单点「皮肤选择」→ 可以看到 7 款皮肤，没解锁的会变暗并显示解锁条件
10. 捡到道具后（血包/火力），右上角格子会亮起并出现「点击使用」→ 点一下就能用掉

> 如果老师要看代码：打开 Android Studio，从 `core/GameWorld.java` 的 `update()` 方法开始讲，
> 那是整个游戏的心脏，一个方法看完就知道游戏怎么跑的了。
