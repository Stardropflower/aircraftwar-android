## 验收时的演示顺序（照着点就行）

1. 打开 App → 开场动画 → 主菜单（星空背景、最高分、四个入口）
2. 点「设置」→ 音乐、音效两个开关分别可关（顺便演示自绘面板）
3. 点「开始游戏」→ 弹出难度面板 → 选「简单」
4. 手指按住屏幕拖动 → 飞机跟着手指走（飞机在手指上方一点，不会被挡住）
5. 松开手指 → 飞机会停在原地，但**子弹一直在自动发射**
6. 让飞机撞一架敌机 → 画面变暗，弹出「游戏结束，本局得分 XX」
7. 点「查看排行榜」→ 直接看到这局成绩写进了 SQLite（实验四重点）
8. 回主菜单点「皮肤选择」→ 7 款皮肤，没解锁的变暗并显示解锁条件
9. 再进一局，点右上角 ⏸ → 「已暂停」；点一下画面继续
10. 捡到道具后（血包/火力），右上角格子亮起并出现「点击使用」→ 点一下就能用掉
11. （如果老师问后续实验）进「联机对战」→ 演示创建房间/加入房间的房间码流程

> 如果老师要看代码：打开 Android Studio，从 `core/GameWorld.java` 的 `update()` 方法开始讲，
> 那是整个游戏的心脏，一个方法看完就知道游戏怎么跑的了。
