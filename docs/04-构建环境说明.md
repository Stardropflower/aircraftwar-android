## 三、⚠️ 中文路径问题（重要）

项目路径含中文（`L:\claudecode\雷霆战机劣质版\`），AGP 在 Windows 上默认**直接拒绝构建**：

```
Your project path contains non-ASCII characters. This will most likely cause the build
to fail on Windows. Please move your project to a different directory.
```

**当前处理**：在 `gradle.properties` 里加了

```properties
android.overridePathCheck=true
```

已实测**完整构建成功**（资源编译、dex、打包全流程通过），APK 可正常产出。

**但仍需知道的潜在风险**：AGP 官方对这个开关的说明是「很可能导致构建失败」，
历史上 AAPT2 对非 ASCII 路径有过问题。目前全流程正常，但如果之后遇到
「资源找不到 / 文件路径乱码 / 打包异常」这类怪问题，**第一嫌疑就是路径**。

**彻底解决办法**（建议在做完实验二后再决定是否执行）：把仓库移到纯 ASCII 路径，例如

```
L:\android-projects\AircraftWar-Android
```

git 仓库整体移动即可，历史不受影响。当前保留中文路径是为了不打断既有的目录组织习惯。

## 四、用 Android Studio 打开

1. 启动 `L:\android-toolchain\android-studio\bin\studio64.exe`
2. 首次启动会提示导入设置，选 **Do not import settings**
3. 在欢迎页 **Open** → 选择 `L:\claudecode\雷霆战机劣质版\AircraftWar-Android`
   （**选这个目录本身，不要选里面的 app 目录**）
4. 首次同步会自动识别 SDK 位置（也可在 SDK Manager 里手动指向 `L:\android-sdk`）
5. 等待 Gradle Sync 完成，即可用 Run 按钮部署

> `local.properties`（记录 `sdk.dir`）已生成且被 `.gitignore` 排除，不会入库。
